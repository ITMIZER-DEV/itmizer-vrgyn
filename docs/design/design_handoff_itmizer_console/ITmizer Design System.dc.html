1ITmizer-VR — Design System: 3 direções

Decisões comuns às três: laranja #FF6A00 é a cor de marca (o azul vira cor semântica de status); light-first; Sora para títulos, Inter para UI; densidade compacta; glass mantido — mas dosado diferente em cada direção. Cada folha mostra tokens, tipo, componentes, tabela e um mock em miniatura do padrão de página aplicado ao Cliente 360.
